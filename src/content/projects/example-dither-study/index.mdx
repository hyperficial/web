## The problem

Animated backgrounds usually mean a video file or a canvas library. Both are heavy for a page that is mostly text. An ordered dither needs one small shader and two colors.

> The constraint was the point: two colors, one shader, no assets.

## How it works

1. Every cell compares a smooth noise value to a threshold from a Bayer matrix.
2. Above the threshold it gets the deep color, below it the base color.
3. The two colors are CSS tokens, so dark mode is free.

```glsl
gl_FragColor = vec4(v > bayer(c) ? hi : lo, 1.);
```
